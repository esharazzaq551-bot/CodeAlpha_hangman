# CodeAlpha_Hangman

A simple text-based Hangman game built in Python for the
CodeAlpha Python Programming Internship (Task 1).

## What it does
- Chooses a random word from a list of 5 predefined words
- The player guesses one letter at a time
- Allows up to 6 wrong guesses
- Shows the word with hidden letters and the guessed letters
- Handles capital letters, repeated guesses and invalid input

## How to run
1. Install Python.
2. Download hangman.py.
3. Run: python hangman.py

## Concepts used
random, while loop, if-else, strings, lists
